# Typography

One family, `font-mono`: Geist Mono, shipped with the app, then the system's monospace. Figures line up in every
row without help, and `tabular-nums` keeps a changing number from shifting its neighbours.

<Story of={Stories.Families} />

## Scale

Sizes are named for their role, in rem so browser zoom and font settings apply. Each size carries its line height, so
`text-body` sets both and lint rejects `leading-*`. `body` is the page default.

<Story of={Stories.Scale} />

<Story of={Stories.Sizes} />

## Small capitals

Labels in `text-micro` are set in capitals with `tracking-caps`, which opens them up enough to read at that size.
